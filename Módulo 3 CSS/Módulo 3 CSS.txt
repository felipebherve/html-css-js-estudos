	- Aula 3 "CSS interno"

Aprendemos a manter uma tag para todo arquivo com apenas um estilo iniciando a
ordem no <head> </head>
	Ex: 
	    <style>
	        h3 {color: darkmagenta}
	    </style>

-------------------------------------<hr>----------------------------------------------

	- Aula 4 "CSS externo"

O css externo é um link para um novo arquivo com propriedades CSS
é necessário criar um arquivo com nome style.css e executar o comando no <head>
de link e abreviação igual quando usamos o comando para colocar um item clicável
sendo href (hyperlink reference)
	Ex:
		<link rel="stylesheet" href="style.css">
