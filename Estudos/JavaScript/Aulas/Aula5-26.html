Aula 5/26 - Tipos de daos

Nos programas de JavaScript, diferentes tipos de dados são usados para representar diferentes tipos de informações. Cada tipo de dado possui características e usos específicos.

Tipo de Dados Básicos

Esses são os tipos de dados fundamentais em JavaScript que você pode entender com relativa facilidade:

  • Number: Números inteiros e decimais.
  • String: Sequências de caracteres.
  • Boolean: Valores verdadeiro ou falso.
  • Undefined: Valor de variável não atribuída.
  • Null: Valor nulo ou vazio.

Tipo de Dados Complexos

Esses tipos de dados podem ser mais complexos de entender e dominar:

  • Object: Estrutura complexa com propriedades e métodos.
  • Array: Coleções ordenadas de valores.
  • Function: Blocos de código executáveis.
  • Symbol: Identificadores únicos.
  • BigInt: Números inteiros arbitrariamente grandes.
  • Map: Estrutura que associa chaves a valores.
  • Set: Coleção de valores únicos.
