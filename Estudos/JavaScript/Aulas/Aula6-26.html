Aula 6/26 - Operações aritméticas

Operações Aritméticas Básicas

Aqui estão as operações aritméticas mais comuns em JavaScript:

  • Adição (+): Realiza a soma de dois valores numéricos.
  • Subtração (-): Subtrai um valor numérico de outro.
  • Multiplicação (*): Multiplica dois valores numéricos para obter um produto.
  • Divisão (/): Divide um valor numérico por outro, resultando em um quociente.
  • Módulo (%): Retorna o restante da divisão de um número pelo outro.
  • Incremento (++): Aumenta o valor de uma variável numérica em 1.
  • Decremento (--): Diminui o valor de uma variável numérica em 1.

Operações Aritméticas Combinadas com Atribuição

Além das operações básicas, você pode usar operações combinadas com atribuição:

  • +=: Adição combinada com atribuição. Exemplo: x += y é equivalente a x = x + y.
  • -=: Subtração combinada com atribuição. Exemplo: x -= y é equivalente a x = x - y.
  • *=: Multiplicação combinada com atribuição. Exemplo: x *= y é equivalente a x = x * y.
  • /=: Divisão combinada com atribuição. Exemplo: x /= y é equivalente a x = x / y.
  • %=: Módulo combinado com atribuição. Exemplo: x %= y é equivalente a x = x % y.

Lembre-se de que a ordem de precedência das operações aritméticas no JavaScript segue as regras matemáticas convencionais.
