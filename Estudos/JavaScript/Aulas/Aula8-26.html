Aula 8 - Operadores Comparativos em JavaScript

Em JavaScript, os operadores comparativos são usados para comparar valores e determinar relações entre eles.

Igual (`==`)

Verifica se dois valores são iguais, realizando uma coerção de tipo se necessário.

console.log(5 == "5"); // true, porque ocorre coerção de tipo e ambos são tratados como o mesmo valor
console.log(true == 1); // true, porque booleanos podem ser convertidos para números (1 para true, 0 para false)

Estritamente Igual (`===`)

Verifica se dois valores são iguais, sem realizar coerção de tipo.

console.log(5 === "5"); // false, 5 numeral é diferente de 5 string
console.log(true === 1); // false, porque os tipos são diferentes
console.log(5 === 5) // true, 5 numeral é igual a 5 numeral

Diferente (`!=`)

Verifica se dois valores não são iguais, com coerção de tipo se necessário.

console.log(5 != "5"); // false, porque ocorre coerção de tipo e ambos são tratados como o mesmo valor
console.log(true != 1); // false, porque booleanos podem ser convertidos para números

Estritamente Diferente (`!==`)

Verifica se dois valores não são iguais, sem realizar coerção de tipo.

console.log(5 !== "5"); // true, porque não ocorre coerção de tipo
console.log(true !== 1); // true, porque os tipos são diferentes

Maior que (`>`)

Verifica se o valor à esquerda é maior do que o valor à direita.

console.log(10 > 5); // true, porque 10 é maior do que 5

Maior ou igual a (`>=`)

Verifica se o valor à esquerda é maior ou igual ao valor à direita.

console.log(10 >= 10); // true, porque 10 é igual a 10

Menor que (`<`)

Verifica se o valor à esquerda é menor do que o valor à direita.

console.log(3 < 7); // true, porque 3 é menor do que 7

Menor ou igual a (`<=`)

Verifica se o valor à esquerda é menor ou igual ao valor à direita.

console.log(5 <= 5); // true, porque 5 é igual a 5
