Aula 5 - Position - Static e Relative


Nesta aula vamos aprender o comando position. ex1.: Usando a configuração position:relative indica que vai ser relativo a configuração padrão. No caso do
quadrado azul colocaremos que ele terá 20px de espaçamento para a esquerda.
O quadrado azul entra para o verde por conta do position não inserir um bloco de espaço como funciona no margin,
quando mexemos no margin o espaço dado entre os blocos iria empurrar o bloco verde para baixo.

Aula 6 - Position Ablosute


O position:absolute ignora a existência do block se tratando da figura, por exemplo,
o quadrado azul deixa de ocupar a posição e existir a margem do block.

Nota: Para que o quadrado em borda seja adotado como base para o position ablosute deve-se ordenar que ele tenha algum position
no caso usado o relative para que a partir disso o quadrado azul tome parte as dimenções adotadas pela borda.
Caso não existisse posicionamento para a borda o quadrado azul adotaria a position pré configurada "no caso a do boddy"
