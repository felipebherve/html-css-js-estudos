Aula 7 - Background

Para modificar a cor do Background usamos o comando background-color:"" este comando permite modificar
o fundo de um documento.
Ex.: usando a cor #34d991 XXXXXXXX

Podemos também adicionar uma imagem como background usando o comando background-image: url(). da imagem"
Ex.: Usando uma imagem que pode ser repetida diversas vezes XXXXXXXX

CASO O FUNDO FOSSE INSERIDO NA PÁGINA TODA SERIA APENAS ORDENAR NO COMANDO CSS PARA O BODY

Caso deseje que a imagem não se repita no fundo deve-se adicionar o comando background-repeat:no-repeat ;
Caso deseje que a imagem não se extenda para o eixo X ou Y usa-se o comando background-repeat: repeat-(x ou y);
Caso deseje que a imagem cubra toda a área se expandindo usa-se o comando background-size: cover;
Caso deseje que a imagem não ande junto com o scroll da página deve-se usar o comando background-attachment: fixed;
Caso deseje que a imagem fique centralizada deve-se usar o comando background-position: center;

Estes comandos todos podem ser feitos em uma única linha desde que respeite a seguinte ordem:
Cor posição/ tamanho se repete origem clipe attachment

Ex.: Background: url(local do arquivo) center/no-repeat fixed ;

Aula 11 - Unidades de Medida (referência)

As unidades de medida de referência são as mais usadas no dia a dia por conta da sua versatilidade
diferente das unidades de medida estáticas.

Seu uso é importante para que a página toda fique com uma estética padronizada sem alteração quando
é necessário diminuir o tamanho da mesma sem deformar alguma imagem ou texto.


Quando não colocamos um tamanho de texto ele vem como base 16 pixels, porém, com o comando no CSS font-size:
conseguimos alterar ele para o tamanho que quisermos.
Neste exemplo usamos o tamanho do texto principal com 20 e o secundário com 2em.
