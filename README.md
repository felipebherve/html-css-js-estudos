# Self-taught: HTML, CSS, JavaScript and Git

🇺🇸 English · 🇧🇷 [Português](README.pt-BR.md)

## Where I was when I made this

This is where my programming journey started, in **2023**. I was working outside of tech and studying on my own: I followed an online web development course (Programador BR) module by module, and wrote my own notes and lesson pages to make sure I really understood each idea. Everything I built later (the JavaScript course, the Django bootcamp, the degree) sits on top of what I practiced here.

## What's inside

| Folder | What it is |
|--------|-----------|
| `Módulo 1`, `Módulo 2 HTML Básico`, `Módulo 3 CSS` | My written notes for the first course modules: how HTML, CSS and JavaScript work together, how a page gets on the internet, tags and page structure, and the three ways to write CSS (inline, internal, external) |
| `html intermediário/` | Intermediate HTML: forms, input types, `select`, `textarea` and an introduction to HTML5 |
| `Projetos/` | The pages I built for each module, including the extra challenges: a beginner HTML site (several linked pages), a CSS beginner page and challenge, an intermediate CSS page, and a minimalist page |
| `Estudos/JavaScript/` | A small site I wrote myself to study JavaScript: one page per lesson (numbered `n/26`), with explanations in my own words and screenshots (Sept–Oct 2023) |
| `Anotações/` | A notes page built with HTML and CSS |
| `Currículo/` | My résumé as a web page, with a PDF version |
| `Projetos GIT/` | My first practice folder for learning Git |
| `script-python/` | Four tiny Python scripts (August 2025), my first contact with Python, using `input()` and `print()` |
| `dúvidas/` | Screenshots of things I got stuck on (for example, a clickable button and hover states), kept to ask about later |

## What I learned

- Writing valid HTML5 with the right structure, forms and semantic tags.
- CSS from the basics (selectors, colours, box model) to intermediate layout, and organizing styles in separate files.
- The first steps of JavaScript in the browser.
- Version control basics with Git: creating a repository, commits, and pushing to GitHub. This is what led to my first published project, [HerveWebDev](https://github.com/felipebherve/HerveWebDev).
- Studying tools: VS Code, Sublime Text and the browser developer tools.

## Status

Finished as a learning stage; it led to my portfolio site [HerveWebDev](https://github.com/felipebherve/HerveWebDev) and, later, to Python and Django in [django-ifrs-estudos](https://github.com/felipebherve/django-ifrs-estudos).

## How to view it

There is nothing to install. Open any `index.html` file in your browser (for example `Projetos/Pagina Minimalista/intex.html` or `Estudos/JavaScript/index.html`).
