# Autodidata: HTML, CSS, JavaScript e Git

🇧🇷 Português · 🇺🇸 [English](README.md)

## Em que momento eu fiz isto

Foi aqui que minha jornada em programação começou, em **2023**. Eu trabalhava fora da área de tecnologia e estudava por conta própria: segui um curso online de desenvolvimento web (Programador BR) módulo por módulo e escrevi minhas próprias anotações e páginas de aula para ter certeza de que realmente entendia cada ideia. Tudo o que construí depois (o curso de JavaScript, o bootcamp de Django, a faculdade) se apoia no que pratiquei aqui.

## O que tem aqui

| Pasta | O que é |
|-------|---------|
| `Módulo 1`, `Módulo 2 HTML Básico`, `Módulo 3 CSS` | Minhas anotações escritas dos primeiros módulos do curso: como HTML, CSS e JavaScript funcionam juntos, como uma página vai para a internet, tags e estrutura da página, e as três formas de escrever CSS (inline, interno, externo) |

| `Estudos/JavaScript/` | Um pequeno site que escrevi para estudar JavaScript: uma página por aula (numeradas `n/26`), com explicações nas minhas palavras e prints (set–out/2023) |

| `script-python/` | Quatro scripts Python minúsculos (agosto de 2025), meu primeiro contato com Python, usando `input()` e `print()` |
| `dúvidas/` | Prints de coisas em que fiquei travado (por exemplo, um botão clicável e estados de hover), guardados para perguntar depois |

## O que aprendi

- Escrever HTML5 válido com a estrutura certa, formulários e tags semânticas.
- CSS do básico (seletores, cores, modelo de caixa) ao layout intermediário, e organização dos estilos em arquivos separados.
- Os primeiros passos de JavaScript no navegador.
- O básico de controle de versão com Git: criar um repositório, commits e enviar para o GitHub. Isso levou ao meu primeiro projeto publicado, o [HerveWebDev](https://github.com/felipebherve/HerveWebDev).
- Ferramentas de estudo: VS Code, Sublime Text e as ferramentas de desenvolvedor do navegador.

## Situação

Concluído como etapa de aprendizado; levou ao meu site de portfólio [HerveWebDev](https://github.com/felipebherve/HerveWebDev) e, depois, ao Python e Django do [django-ifrs-estudos](https://github.com/felipebherve/django-ifrs-estudos).

## Como ver

Não é preciso instalar nada. Abra qualquer arquivo `index.html` no navegador (por exemplo `Projetos/Pagina Minimalista/intex.html` ou `Estudos/JavaScript/index.html`).
