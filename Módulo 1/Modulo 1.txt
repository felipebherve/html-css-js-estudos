CSS: como o conteúdo vai aparecer na tela (para dar o design dos botões e como vai aparecer

Java: interação (é responsável por trabalhar toda a interação que temos com a página. (clicar, mover etc..))

	Aula "Frontend e Backend"

como funciona o processo?
Meu pc > Servidor > meu pc
Cliente > servidor > cliente
Tudo que rola no meu computador após o servidor 
me mandar de volta é o front end 

tudo que é executado pelo servidor é o backend
"renderizar é oque o servidor faz"> server side render

O servidor pega os arquivos e atualiza no template (cara do site)
(página dinamica) página que modifica dependendo do teu acesso

>> servidor de DNS (Domain name server): ele interpreta o IP da hospedagem
para que ela seja exibida em qualquer computador
