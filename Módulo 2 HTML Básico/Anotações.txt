	Aula "Formatação"

Tags de formatação:

Para colocar em negrito 
<b>negrito</b> 
Para ser destacada para pesquisa
<strong>negrito</strong>

Para colocar em itálico
<i>itático</i>
Para ser mais destacado para pesquisa
<em>Ênfaze</em>

Para marcar um texto
<mark> marcado </mark>

Para diminuir o texto
<small> texto fica menor </small>

Para riscar o texto
<dell> texto riscado </dell>
Para destacar para pesquisa texto riscado
<s> texto riscado </s>

Para inserir um texto
<ins> texto sublinhado </ins?
Texto sublinhado para pesquisa
<u> texto sublinhado </u>

Para colocar um texto abaixo da linha de texto
<sub> texto abaixo </sub>

Para colocar um texto ascima da linha  de texto
<sup> texto ascima </sup>

	Aula "Imagens"

Para adicionar uma imagem <img src="link da imagem">
Caso a página precise de indicação para a imagem 
<img src="Link da imagem" alt="indicação de imagem">

Caso a imagem esteja na mesma pasta ou numa pasta em nível superior
<img src="pasta base/arquivo.jpg" alt="indicação de imagem">

Caso deseje que a imagem vire um link
<a href="nome da página que quer botar">
<img src="pasta base/arquivo.jpg" alt="indicação de imagem"> 
</a>
(nota-se que se inicia com <a.. e termina o </a> apenas após toda a 
composição da imagem

Para diminuir ou aumentar proporções da imagem
<img src="pasta base/arquivo.jpg" alt="indicação de imagem" width=valor>
(alterar a largura)
<img src="pasta base/arquivo.jpg" alt="indicação de imagem" height=valor>
(alterar a altura)
